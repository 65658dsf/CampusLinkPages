从第一次安装，到每天轻松上线。这份指南带你了解岚连 Campus Link 的连接、状态检查、启动设置和问题排查。

适用于 Windows x64 客户端 v1.0.2，开发者 NingMeng123。内置贵州轻工职业大学方案；其他学校可导入经过核实的连接配置。

安装与首次登录

  1. 前往下载区域获取 Windows x64 安装程序，运行后选择安装位置。
  2. 先通过 Windows 连接校园 Wi-Fi，或插入校园网网线，再打开“岚连 Campus Link”。
  3. 等待启动检测。已登录时直接查看在线信息；尚未登录时，选择“贵州轻工职业大学”，网络类型保持“校园网”。
  4. 填写学校提供的认证账号和密码，按需勾选“记住密码”，点击“连接校园网”。

岚连负责校园网认证。连接 Wi-Fi、选择无线网络和排查网线接入，仍需在 Windows 中完成。

已安全保存密码时，输入框显示“已安全保存，留空使用”。只有当前账号与连接方案对应的已保存密码可以继续使用；更换账号后请重新填写。

理解连接状态

每次打开应用都会先检查当前设备是否通过认证，不要求保存密码或开启自动连接。浏览器中已经登录的设备，也会直接显示“已登录校园网”，隐藏登录表单。

界面状态含义与操作
正在检测正在查询认证状态，等待检查完成。
已登录校园网已确认在线，可查看会话信息、刷新状态或主动注销。
等待连接当前未认证，接入校园网络后可以填写账号登录。
状态待确认或连接需要处理暂时无法确认状态。查看提示和日志，不应直接理解为已断开。

应用运行时每 30 秒自动刷新，返回窗口时也会检查；连续自动检查至少间隔 5 秒，正在处理请求时跳过。需要立即确认时，点击“检测网络”或“刷新状态”。这些检查只查询状态，不会反复提交登录。

按需设置启动方式

“连接偏好”和“应用设置”都有两个独立开关，默认均关闭：

  • 开机自启动：登录 Windows 后启动岚连。仅安装后的 Windows 版本可用，启动后可从系统托盘打开窗口。
  • 启动后自动连接：使用已保存的认证信息登录。请先勾选“记住密码”并保存账号密码，再开启此项。

自动连接只在启动时尝试一次：先检测，已在线就跳过，确认未认证才登录，状态未知则停止本次尝试。它不是持续断线重连服务。如果开机时校园网络还未就绪，接入网络后手动连接即可。

只开启“开机自启动”不会自动认证。清除密码、取消记住密码或更换认证身份后，自动连接也会关闭。

托盘、退出与注销

“关闭时最小化到托盘”默认开启。点击右上角关闭按钮后，应用继续在后台运行；双击 Windows 系统托盘中的岚连图标可恢复窗口。

右键托盘图标可查询认证状态、断开认证或选择“退出岚连”。真正结束校园网认证，请点击界面的“注销校园网”或托盘的“断开认证”；仅关闭窗口或退出应用不会主动注销现有连接。

导入、导出与更新连接方案

外部方案是描述认证请求的 JSON 配置。它可定义学校地址、请求参数、自定义输入项和响应判断，不会执行第三方脚本或程序。

  1. 进入“连接方案”，点击“导出方案示例”，保存一份可编辑的示例文件。
  2. 依据目标学校的真实接口修改配置，以 UTF-8 保存为 JSON。示例地址是占位符，不能直接登录。
  3. 点击“导入连接方案”，核对认证地址并导入。导入只校验和保存配置，不会自动登录。
  4. 在方案卡片点击“使用此方案”，返回连接概览填写认证信息。

每个文件最多 64 KB，最多导入 30 个外部方案。相同 ID 不会自动覆盖；更新时先移除旧方案再导入，或使用新 ID。已认证时需先注销才能切换方案，内置方案不能删除。

当前外部方案须同时提供登录、注销和只读状态查询，接口须与认证页同源。动态验证码、多步令牌流程等认证方式需要额外适配，不能只靠 JSON 完成。字段说明与完整示例见连接方案开发指南。

通过日志查看服务器响应

“活动日志”保留本次运行最近 100 条记录，可按信息、成功、提醒和错误筛选。“复制日志”复制当前筛选结果的摘要。

连接失败时，在“最近活动”或“活动日志”点击“查看响应”，可看到错误代码、请求方法、去掉查询参数的地址、HTTP 状态、响应类型、耗时和脱敏正文。一次操作涉及多次请求时，会分别列出。没有网络响应详情的错误可点击“查看详情”查看摘要。

响应以纯文本显示，每次请求最多保留 16 KiB，超过后会提示截断。点击“复制详情”可复制诊断内容，按 Esc 或关闭按钮退出详情窗口。

诊断记录只保留在当前进程内存中，不写入设置或日志文件。退出应用后清除；主动复制的内容会进入系统剪贴板。

密码与本地数据

记住密码后，Windows 客户端使用系统 DPAPI 加密保存，保护范围与当前 Windows 用户相关。未勾选时，密码只用于当前运行，不持久保存。系统安全存储不可用时，可取消记住密码后手动连接。

在“应用设置 → 账号与隐私”点击“清除密码”，可移除已保存密码并关闭自动连接。账号、连接方案和偏好仍是本地设置；自定义字段不是密码存储位置，请勿填入令牌等凭据。

本地加密不会改变认证请求的传输方式：贵州轻工职业大学当前使用 HTTP。导入其他方案时，请核对学校提供的地址。卸载默认保留本地设置，需要移除凭据时请先清除密码。

常见问题

看到 error5 或 waitsec，要改密码吗？

不能仅凭这个提示判断密码错误。已有用户确认，遇到等待提示后稍等一会儿再连接即可恢复。先停止连续点击，等待后重试；仍失败时查看响应详情，并用学校认证页核对结果。HTTP 200 也只代表收到响应，不一定代表认证成功。

提示无法访问服务器或响应无法识别

先确认已接入校园网络，再点“打开认证页”。浏览器也打不开时，检查网络接入与学校服务；浏览器正常时，将日志中的状态码和响应详情作为排查依据。新版已修正内置登录请求参数顺序。

浏览器已登录，应用还没更新

返回岚连后等待自动检查，或手动“检测网络”。状态查询失败时会保留待确认提示，请查看日志，无需为了刷新状态先注销。

启动开关无法开启

开发模式和浏览器预览不能注册 Windows 自启动，请使用安装版并检查系统的“启动应用”设置。自动连接还需要已保存的账号密码和可用的系统安全存储。

方案导入失败

检查 JSON 格式、文件大小、ID 是否重复，以及接口是否同源、变量是否声明。具体错误可对照方案字段说明处理。

更新客户端

先从系统托盘选择“退出岚连”，再通过下载区域获取新版安装程序，建议选择原安装位置。安装后打开“应用设置”，核对版本号并检测网络。

当前采用手动下载安装更新。更新后检查连接方案和启动偏好；若系统提示保存的密码无法解密，重新输入并保存即可。退出和安装过程中，岚连不会主动注销已有校园网会话。
