从第一次安装，到每天轻松上线。这份指南带你了解岚连 Campus Link 的连接、断线自动重连、启动设置和问题排查。

适用于 v1.1.0：Windows x64，以及 macOS Intel x64 / Apple 芯片 arm64。开发者 NingMeng123。内置贵州轻工职业大学方案；其他学校可导入经过核实的连接配置。

安装与首次登录

  1. 从下载区域进入 CampusLink 发布页，按操作系统与芯片选择文件并完成安装。
  2. 先在系统中连接校园 Wi-Fi，或插入校园网网线，再打开“岚连 Campus Link”。
  3. 等待启动检测。已登录时直接查看在线信息；尚未登录时，选择“贵州轻工职业大学”，网络类型保持“校园网”。
  4. 填写学校提供的认证账号和密码，按需勾选“记住密码”，点击“连接校园网”。

岚连负责校园网认证。连接 Wi-Fi、选择无线网络和排查网线接入，仍需在 Windows 或 macOS 的网络设置中完成。

已安全保存密码时，输入框显示“已安全保存，留空使用”。只有当前账号与连接方案对应的已保存密码可以继续使用；更换账号后请重新填写。

Windows x64

选择 Windows 的 EXE 安装程序，按向导选择安装位置。升级时先从系统托盘完全退出旧版，再运行新安装程序。

macOS：选对芯片架构

Apple 芯片的 Mac 选择 arm64，Intel Mac 选择 x64，可在系统“关于本机”中确认。发布目标包含 DMG 与 ZIP：打开 DMG 后将应用拖入“应用程序”；ZIP 解压后将应用移入“应用程序”，再从该位置启动。实际可下载文件以 CampusLink 发布页附件为准。

当前提供 macOS 构建支持，尚未完成 Mac 真机上的校园认证、钥匙串和登录项验收。具体构建、签名和实测范围请查看对应版本的发布说明。

未签名或未经公证的 macOS 构建可能受到系统运行与登录项限制，开机自启动可能不可用。请核对发布页的签名与公证说明；自启动受限时可手动打开客户端。

理解连接状态

每次打开应用都会先检查当前设备是否通过认证，不要求保存密码或开启自动连接。浏览器中已经登录的设备，也会直接显示“已登录校园网”，隐藏登录表单。

界面状态含义与操作
正在检测正在查询认证状态，等待检查完成。
已登录校园网已确认在线，可查看会话信息、刷新状态或主动注销。
等待连接当前未认证，接入校园网络后可以填写账号登录。
状态待确认或连接需要处理暂时无法确认状态。查看提示和日志，不应直接理解为已断开。

启动检查始终执行。网络守护开启且未暂停时，返回窗口或从睡眠恢复也会查询状态；连续自动检查至少间隔 5 秒，正在处理请求时跳过。需要立即确认时，点击“检测网络”或“刷新状态”。确认在线后，按设置的间隔启动周期检测；具体重连条件见下节。

网络守护与断线自动重连

“断线自动重连”默认开启，检测间隔默认 30 秒。应用成功连接或状态查询确认在线后开始守护；从未确认在线、尚未完成首次认证时，不会靠这一开关自动发起首次登录。

  1. 进入“应用设置 → 网络守护”，按需开启或关闭“断线自动重连”。连接概览的“连接偏好”也有同一开关。
  2. 在“检测间隔（秒）”输入 5–3600 之间的整数，再点击“保存间隔”。输入时不会立即改变设置。
  3. 观察守护状态：确认断线时，使用本次连接的认证信息或本机已保存的密码尝试重新认证。

超时、服务器不可达或无法识别的响应属于“状态未知”，不会当作断线直接提交密码。若没有可用凭据，例如仅在浏览器中登录且应用从未保存密码，日志会提示手动连接；开启守护不保证每次重连都成功。

不勾选“记住密码”也能使用本次运行中成功认证的凭据重连，退出应用后这份内存凭据即失效。需要跨次启动使用密码，请按需勾选记住密码。

在应用内手动“注销校园网”会立即暂停守护，即使注销请求失败也不会自动登录回去。再次手动连接成功后恢复；单纯刷新状态不会撤销这次暂停。

按需设置启动方式

“连接偏好”和“应用设置”都有两个独立开关，默认均关闭：

  • 开机自启动：登录 Windows 或 macOS 后启动岚连，安装版可用。macOS 是否能注册登录项受应用签名和系统设置影响。
  • 启动后自动连接：使用已保存的认证信息登录。请先勾选“记住密码”并保存账号密码，再开启此项。

“启动后自动连接”只在启动时尝试一次：先检测，已在线就跳过，确认未认证才登录，状态未知则停止本次尝试。如果开机时校园网络还未就绪，接入网络后手动连接即可。在线后的持续检测由独立的“断线自动重连”控制。

只开启“开机自启动”不会自动认证。清除密码、取消记住密码或更换认证身份后，“启动后自动连接”也会关闭；它与默认开启的断线自动重连是两个设置。

托盘、退出与注销

“关闭时最小化到托盘”默认开启。点击关闭按钮后，应用继续在后台运行。Windows 可从系统托盘恢复窗口；macOS 可从菜单栏图标的菜单显示窗口。

图标菜单可查询认证状态、断开认证或选择“退出岚连”。点击界面的“注销校园网”或菜单的“断开认证”，会提交注销并暂停自动重连。仅关闭窗口或退出应用不会主动注销现有连接；完全退出后不再进行后台检测。

导入、导出与更新连接方案

外部方案是描述认证请求的 JSON 配置。它可定义学校地址、请求参数、自定义输入项和响应判断，不会执行第三方脚本或程序。

  1. 进入“连接方案”，点击“导出方案示例”，保存一份可编辑的示例文件。
  2. 依据目标学校的真实接口修改配置，以 UTF-8 保存为 JSON。示例地址是占位符，不能直接登录。
  3. 点击“导入连接方案”，核对认证地址并导入。导入只校验和保存配置，不会自动登录。
  4. 在方案卡片点击“使用此方案”，返回连接概览填写认证信息。

每个文件最多 64 KB，最多导入 30 个外部方案。相同 ID 不会自动覆盖；更新时先移除旧方案再导入，或使用新 ID。已认证时需先注销才能切换方案，内置方案不能删除。

当前外部方案须同时提供登录、注销和只读状态查询，接口须与认证页同源。动态验证码、多步令牌流程等认证方式需要额外适配，不能只靠 JSON 完成。字段说明与完整示例见连接方案开发指南。

通过日志查看服务器响应

“活动日志”保留本次运行最近 100 条记录，可按信息、成功、提醒和错误筛选。“复制日志”复制当前筛选结果的摘要。

连接失败时，在“最近活动”或“活动日志”点击“查看响应”，可看到错误代码、请求方法、去掉查询参数的地址、HTTP 状态、响应类型、耗时和脱敏正文。一次操作涉及多次请求时，会分别列出。没有网络响应详情的错误可点击“查看详情”查看摘要。

响应以纯文本显示，每次请求最多保留 16 KiB，超过后会提示截断。点击“复制详情”可复制诊断内容，按 Esc 或关闭按钮退出详情窗口。

诊断记录只保留在当前进程内存中，不写入设置或日志文件。退出应用后清除；主动复制的内容会进入系统剪贴板。

密码与本地数据

记住密码后，Windows 使用系统 DPAPI 加密，macOS 使用由钥匙串保护的系统加密存储。保护范围与当前系统用户相关。未勾选时，密码仅用于本次运行中的认证和重连，不持久保存；系统安全存储不可用时，仍可手动连接。

在“应用设置 → 账号与隐私”点击“清除密码”，会移除已保存密码和本次重连凭据，关闭启动后自动连接。若后续守护确认断线且无凭据，将提示手动连接。账号、连接方案和偏好仍是本地设置；自定义字段不是密码存储位置，请勿填入令牌等凭据。

本地加密不会改变认证请求的传输方式：贵州轻工职业大学当前使用 HTTP。导入其他方案时，请核对学校提供的地址。卸载默认保留本地设置，需要移除凭据时请先清除密码。

常见问题

看到 error5 或 waitsec，要改密码吗？

不能仅凭这个提示判断密码错误。已有用户确认，遇到等待提示后稍等一会儿再连接即可恢复。先停止连续点击，等待后重试；仍失败时查看响应详情，并用学校认证页核对结果。HTTP 200 也只代表收到响应，不一定代表认证成功。

提示无法访问服务器或响应无法识别

先确认已接入校园网络，再点“打开认证页”。浏览器也打不开时，检查网络接入与学校服务；浏览器正常时，将日志中的状态码和响应详情作为排查依据。新版已修正内置登录请求参数顺序。

浏览器已登录，应用还没更新

返回岚连后等待自动检查，或手动“检测网络”。状态查询失败时会保留待确认提示，请查看日志，无需为了刷新状态先注销。

为什么开启了自动重连，还需要手动连接？

检查是否已经成功认证并开始守护、是否刚手动注销而暂停，以及是否有本次运行或已保存的认证凭据。只有明确离线才会尝试重连；状态未知或没有凭据时会提示处理。可在活动日志中查看具体原因。

启动开关无法开启

开发模式和浏览器预览不注册自启动。Windows 安装版可检查系统“启动应用”；macOS 可检查系统登录项和发布页的签名、公证说明，未签名或未公证版本可能无法启用。启动后自动连接还需要已保存的账号密码和可用的系统安全存储。

方案导入失败

检查 JSON 格式、文件大小、ID 是否重复，以及接口是否同源、变量是否声明。具体错误可对照方案字段说明处理。

更新客户端

先从托盘或菜单栏菜单选择“退出岚连”，再通过下载区域进入 CampusLink Releases。Windows 运行新版安装程序；macOS 选择正确架构的 DMG 或 ZIP，替换“应用程序”中的旧版。打开“应用设置”，核对版本号并检测网络。

当前采用手动下载安装更新。更新后检查连接方案和启动偏好；若系统提示保存的密码无法解密，重新输入并保存即可。退出和安装过程中，岚连不会主动注销已有校园网会话。
